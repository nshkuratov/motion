# MOTION documentation / Документация MOTION

## Complete build guides / Полные руководства

- **[English: Building a layered cinematic website](build-guide.en.md)** — 24 chapters covering the complete production process, from artwork preparation to deployment.
- **[Русский: Как создать многослойный сайт с кинематографичной анимацией](build-guide.ru.md)** — 24 раздела о полном процессе: от подготовки изображений до публикации.

Both editions cover the same implementation and include linked source files, practical code, exact current settings, asset dimensions, troubleshooting, and a staged acceptance checklist. Read section 2 to reproduce the existing project; work through the full guide to create a similar site with new artwork.

Обе версии описывают одну реализацию: содержат ссылки на исходники, примеры кода, точные настройки, размеры изображений, диагностику и пошаговую проверку. Для воспроизведения проекта начните с раздела 2; для нового сайта с собственной графикой прочитайте руководство последовательно.
